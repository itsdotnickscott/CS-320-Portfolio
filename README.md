# CS 320 Portfolio

How can I ensure that my code, program, or software is functional and secure?
- There are multiple ways to ensure your code is functional and secure
- For example, code reviews are important to check for logical deficiencies
- Extra sets of eyes and perspectives are always helpful
- Unit tests directly test your code to make sure it is working as expected
- Test coverage shows how much of your code is being ran while tested
- By utilizing multiple testing strategies, you can make sure your software is both functional and secure

How do I interpret user needs and incorporate them into a program?
- Starting with a list of desired functionality, I list them out in bullet points to organize my thoughts
- After, I can organize the notes into groups or sections of matching or similar functionality
- Thinking like an end user and testing your software as if you will be a future user is important
- By considering the end user and their experience, your program has higher quality as they will be the primary users of the program.

How do I approach designing software?
- I can take my notes or bullet points from a software and turn them into diagrams or flowcharts to help understand systems and logic
- Recorded transcripts of clients who want software built, or a mind map organization of my own thoughts will be helpful
- Thinking about how software can be grouped into classes and objects will be essential for OOP
- Designing functions with corresponding test functions will ensure that the software is built correctly and working as expected
- The "structure" or system design should be planned out before implementation (ie. knowing the classes, attributes, functions, etc.)
